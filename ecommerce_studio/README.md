# Ecommerce AI Studio (电商智能策划与生图工作台)

基于多模态大模型（Vision LLM）与多智能体（Multi-Agent）协同架构的**端到端电商营销设计工作台**。

---

## 🌟 核心特性矩阵

### 1. 💬 会话管理与本地持久化 (全新特性)
- **多会话并行与历史归档**：侧边栏支持【➕ 新建策划会话】与历史方案下拉切换，自动记录方案标题、修改时间与已生成图片数。
- **持久化本地存储**：自动将商品表单、9 大图提示词矩阵、图片列表与多轮对话实时持久化在 `ecommerce_studio/sessions/`，刷新或重启服务数据永不丢失。
- **AI 创意顾问多轮对话工坊**：内置 `st.chat_message` 多轮交互窗口，AI 顾问自动结合当前商品卖点、痛点策划案与 9 图提示词，支持探讨详情页排版、电商文案优化与构图调整。

### 2. 🎨 电商 9 大图视觉矩阵与 100% 中文生图提示词 (全新特性)
- **电商必备 9 大视觉资产全覆盖**：
  1. 商业高清白底首图
  2. 真实生活使用场景图
  3. 核心卖点与功能特写图
  4. 材质工艺与微距细节图
  5. 痛点场景攻坚图 (防漏水/保温冷凝/耐磨抗摔)
  6. 便携携带与通勤场景图
  7. 结构卖点与内胆透视图
  8. 包装礼盒与配件开箱图
  9. 真实模特生活方式交互图
- **商业级中文提示词体系**：彻底摒弃传统生硬英文 Prompt，全面采用包含商业摄影三点布光、机位角度、材质质感与景深氛围的高质量中文生图 Prompt。
- **人在回路 (Human-in-the-Loop) 分段微调**：每个视角提供独立卡片与中文编辑框，支持分别微调与单独测试生成。

### 3. 🖼️ 一键批量生成 9 张图与 3×3 九宫格画廊 (全新特性)
- **并发批量生图引擎**：基于多线程并发加速生成 9 张商业大片，支持动态进度条实时追踪。
- **3×3 九宫格画廊**：高质感网格展示，每张图片显示视角标签、状态徽章、提示词微调与单图下载。
- **一键交付物导出**：支持【📦 一键打包下载全部 9 张图片 (ZIP)】与【📥 导出完整策划案 (MD)】。

### 4. 🪄 单图二次 AI 调整重绘 (全新特性)
- **自然语言重塑画面**：在九宫格画廊的任意已生成图片下方点击【🪄 二次 AI 调整重绘】。
- **智能重写与即时重绘**：输入修改意见（例如：“换成晚霞黄昏逆光光影”、“桌面放一本商务手账”），AI 自动结合原图 Prompt 重塑中文提示词，一键重绘并原地替换原图，同步持久化存盘。

### 5. ⚙️ 模型凭证与自定义扩展
- **双大模型 Provider 支持**：Google Gemini 与 OpenAI 原生支持。
- **自由自定义模型**：多模态理解模型与生图模型均支持下拉预选或选择【✏️ 自定义输入 / Custom】直接填入任意微调模型 ID。

## 🚀 快速启动

### 1. 启动 Web 工作台
在工程根目录下执行：
```bash
streamlit run ecommerce_studio/app.py
```
终端输出访问链接后，在浏览器中打开 `http://localhost:8501`。

### 2. 操作流步骤说明
1. **侧边栏配置**：填入 Gemini 或 OpenAI 的 API Key，点击「💾 保存配置」。
2. **会话与商品输入**：
   - 可在侧边栏点击「➕ 新建策划会话」或直接在主界面输入商品名称、品类属性、目标客群、竞品短板。
   - 上传 1~5 张商品实拍白底图或细节图。
3. **阶段一（策划生成）**：
   - 点击【🚀 启动 AI 痛点挖掘与 9 大图视觉矩阵策划】。
   - 系统输出营销分析方案，并在下方渲染出电商 9 大图的中文提示词卡片。
4. **阶段二（微调与批量出图）**：
   - 可在 9 个 Tab 中微调中文提示词，也可以在对话窗口与 AI 顾问讨论方案。
   - 点击【🎨 一键生成全套 9 张电商图】，九宫格画廊实时并发渲染出图。
5. **阶段三（二次 AI 调整与交付）**：
   - 对不满意的图片，展开其卡片下的【🪄 二次 AI 调整重绘】输入修改意见重绘。
   - 点击【📦 一键打包下载全部 9 张图片 (ZIP)】即可完成商用交付！
